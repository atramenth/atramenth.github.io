# Turkish sūrah texts

Not translated yet. Sūrahs fall back to English until a file exists here.

To add one, copy `../sNNN.ts` to `sNNN.ts` in this folder and translate the text. Keep the same
`number`, verse numbers and `{n}` footnote markers. The reader picks it up automatically in Turkish;
no registration is needed, and `npm run check:data` validates it.
